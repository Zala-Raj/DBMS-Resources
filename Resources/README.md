# Other Learning Resources

This section contains other useful study materials and reference resources collected from different sources to help students with DBMS and SQL learning.

I'll keep adding useful materials as I find them, so this section may be updated regularly.

## Available Resources

You can find various educational materials in the collection, including:

- **Books** – Reference books and textbooks for DBMS.
- **Syllabus** – Subject syllabus and course details.
- **Question Banks** – Important questions and practice questions.
- **PYQs** – Previous Year Question Papers.
- **PPTs** – Presentation slides and study material.
- **Notes** – Additional notes and reference material.
- **Lab Manuals** – Practical manuals and experiment references.
- **Important Questions** – Questions useful for exam preparation.
