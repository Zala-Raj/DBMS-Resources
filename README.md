# DBMS Resources

A collection of learning materials, notes, and SQL resources for students learning **Database Management Systems (DBMS)**.

This repository is created to make DBMS learning easier by bringing useful study resources together in one place.

## What's Inside?

| Section | Description |
|---|---|
| DBMS Notes | Topic-wise theoretical notes available through Notion |
| SQL Learning | SQL concepts, syntax, examples, and learning notes |
| Resources | Useful websites, books, videos, and references |

## Explore the Repository

- [Notes](https://github.com/Zala-Raj/DBMS-Resources/tree/main/Notes)
- [SQL](https://github.com/Zala-Raj/DBMS-Resources/tree/main/SQL)
- [Additional Resources](https://github.com/Zala-Raj/DBMS-Resources/tree/main/Resources)

## Who Is This For?

- Students studying Database Management Systems.
- Beginners learning SQL.
- Students preparing for DBMS examinations and practicals.
- Anyone looking for organized DBMS learning resources.

## Learning Resources

Some notes are hosted on Notion and can be accessed through the links provided in the respective sections.

Additional learning material may include external courses, documentation, and educational resources. Original creators and sources will be credited wherever applicable.
